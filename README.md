A deadpan error message from a toaster that has had enough: it ran its
checks, found no bread, and now politely asks the human to do the one job
the toaster cannot — while calling out the awkward staring into the empty
slot. One line, under 120 characters, delivered with the weary dignity of
a kitchen appliance that knows it is not the problem.

## How to run

```bash
node main.ts
```

This writes the entry line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program
throws if the line is not 1–120 characters.
